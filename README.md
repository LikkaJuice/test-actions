# Test Actions

Простой тестовый бэкенд на FastAPI, возвращающий текущее время сервера.

## Требования

- Python 3.10 или новее

## Установка

```bash
cd test-actions
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
uvicorn main:app --reload
```

Сервер будет доступен по адресу `http://127.0.0.1:8000`.

## Эндпоинты

| Метод | Путь    | Описание                                   |
|-------|---------|--------------------------------------------|
| GET   | `/`     | Проверка работоспособности сервера          |
| GET   | `/time` | Текущее время сервера (UTC и локальное)     |
| GET   | `/docs` | Интерактивная документация (Swagger UI)      |

### Пример ответа `GET /time`

```json
{
  "utc": "2026-08-29T12:30:00.000000+00:00",
  "local": "2026-08-29T15:30:00.000000+03:00",
  "timezone": "UTC+03:00"
}
```
